# Benchmark Results

The timed benchmark results of SyntaxIR are measured and kept in the repository
[syntaxir/bench](https://github.com/syntaxir/bench), whose harness runs the benchmarks of a SyntaxIR
checkout by the [timed measurement method](performance.md#timed-measurement-method) and publishes
each set of results as a release tagged `results-vN`. The results cover every SyntaxIR backend
(closure, recursive and iterative bytecode VMs, Go parsers generated by `sxir gen`), the generated
TypeScript parsers and, where a comparable parser exists, the Go standard library;
[performance.md](performance.md) analyses them.

The timing figures of the release that is pinned now predate the timed measurement method: they are the median of
three runs of 2026-10-29, with no A/A control, and stand until a timed run in a declared measurement window on the
reference machine replaces them. The parser sizes are deterministic and do not depend on the method.

[`site/benchmarks.json`](../site/benchmarks.json) pins the release that this version of SyntaxIR
quotes, with the SHA-256 digests of its `RESULTS.md` and `figures.json`. On the
[web site](https://syntaxir.dev/docs/benchmarks/), this page is that release's `RESULTS.md`, which
the site build downloads and checks against the pin. The documents quote figures of the pinned
release, which [`site/figures.json`](../site/figures.json) copies; a test of the site checks every
quote against it.
