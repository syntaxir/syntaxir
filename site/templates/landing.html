Where SyntaxIR fits

      
Five workloads where hand-written parsers or single-target generators break down.

    

    

      

        
        
Shared DSLs across runtimes

        
Ship a filter, query or policy language to every service and front end from one grammar, in Go and TypeScript today. Conformance tests hold every backend to the same trees and errors.

      


      

        
        
Keystroke-speed editors

        
A Document reuses every rule result an edit did not touch: an edit and reparse of 100,000 lines takes about 1–2 ms. Declared recovery keeps a tree for unfinished code.

      


      

        
        
Safe parsing for untrusted input

        
Cost analysis proves linear time for grammars that meet its conditions and flags super-linear rules before you ship. Compute and nesting limits, on by default, stop hostile input.

      


      

        
        
Stream large logs and datasets

        
Parse CSV, NDJSON or structured logs record by record as bytes arrive from an io.Reader. Memory follows the size of one record, not of the input.

      


      

        
        
Develop real programming languages

        
Express indentation-sensitive blocks, whole operator precedence tables, left recursion and recovery from syntax errors directly in the grammar, then build the language with the toolchain around it: a language server with diagnostics, completion, hover, go to definition, references, rename and formatting; lint and complexity classification; trace, profile and explain for every rule call, its cost and the cause of an error; and sampled inputs, fixture tests and edit fuzzing against fresh parses. The ready-made parsers for Go 1.27, Python 3.14, TypeScript 5.9 and DuckDB SQL are written this way.

      

    

  






  

    

      
Let LLMs write the grammar. Let SyntaxIR check it.

      
A hand-written parser from an LLM hides backtracking bugs and drifts between languages. A grammar is short enough to review, and SyntaxIR checks it automatically: the checks feed their diagnostics back until the grammar passes.
